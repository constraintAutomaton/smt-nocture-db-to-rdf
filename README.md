# smt-nocture-db-to-rdf

Generator of an RDF dataset of demon information from [Shin Megami Tensei III: Nocturne](https://en.wikipedia.org/wiki/Shin_Megami_Tensei_III:_Nocturne).

### Usage

This project uses a `makefile`. The simplest way to build the entire RDF dataset is:
```sh
make all
```
To customize the domain name used in the RDF documents, run:
```sh
make all DOMAIN_NAME="https://my-cool-domain-name.foo"
```
